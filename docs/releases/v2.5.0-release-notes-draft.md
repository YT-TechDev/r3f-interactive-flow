# r3f-interactive-flow v2.5.0

v2.5.0 focuses on real-world usage validation and evidence-backed integration
guidance while preserving the stable v2 runtime and public API.

### Highlights

- Added a standalone Vite + React Three Fiber consumer that validates
  package-root imports against the published `r3f-interactive-flow@2.4.0`
  package outside the workspace.
- Recorded representative desktop browser, physical mouse, high-resolution
  trackpad, physical keyboard, responsive emulation, touch emulation, and
  physical iPhone Safari usage.
- Recorded 82 PASS scenarios, 0 FAIL scenarios, 0 BLOCKED scenarios, and 1
  optional UNVERIFIED physical-tablet environment.
- Added evidence-backed README and guide updates for package-root imports,
  DOM/Canvas responsibility boundaries, input handling, nested scroll regions,
  and application-owned reduced-motion policy.

### Validated behavior

- Package-root imports cover the existing public API without relying on package
  subpaths.
- DOM navigation and transition progress remain active without Canvas.
- Canvas observation resumes after the Canvas is unmounted and remounted while
  the provider-owned flow continues.
- Wheel, trackpad, touch, and keyboard handling preserve native browser behavior
  for rejected input.
- Browser event `preventDefault()` behavior remains accepted-only for flow
  navigation.
- Ignored nested-scroll regions preserve native scrolling and do not trigger
  flow navigation.
- Reduced motion remains application-owned configuration, not an automatic
  library policy.

The physical and browser validation used the published
`r3f-interactive-flow@2.4.0` package. v2.5.0 preserves that runtime source and
adds validation evidence, documentation, and release metadata. The optional
physical-tablet lane was not tested and is not claimed as validated.

### Compatibility

- No runtime source changes from 2.4.0.
- No public API additions or removals.
- No public TypeScript type changes.
- No package export changes.
- No runtime dependency additions.
- No peer dependency range changes.
- The root-only package boundary remains unchanged.
- This release is not broad browser certification.
