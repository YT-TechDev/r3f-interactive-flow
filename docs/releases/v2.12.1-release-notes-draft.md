## Proposed GitHub Release

# r3f-interactive-flow v2.12.1

### Summary

`v2.12.1` is a backwards-compatible, tooling-only maintenance release of
`r3f-interactive-flow`. Since `v2.12.0`, repository development, CI,
and example dependencies were refreshed. The library itself has no runtime
bug fixes, new features, or consumer-facing behavior changes in this patch.

### Maintenance updates

- #499 — refresh the grouped workspace and example dependencies, including
  React, React DOM, React Three Fiber, Three.js, Playwright, and Vite.
- #500 — update the pinned GitHub Actions `setup-node` version.
- #502 — update Vite in the published-package consumer validation fixture.
- #503 — align Vitest and browser adapter at `4.1.11`.
- #504 — update Vite to `8.3.3` and refresh its lockfile-resolved tooling.

### Compatibility and migration

There are no changes to library runtime source, public APIs or exported types,
package entry points, runtime dependencies, or peer dependency ranges.
No migration is required. Consumers should not expect new runtime fixes
or features from this tooling-only patch.

### Validation boundaries

Before publication, the exact v2.12.1 candidate must be checked by CI:

- `pnpm install --frozen-lockfile`
- `pnpm audit --prod`
- `pnpm build`, package verification and packed consumer smoke
- supported peer compatibility, typecheck, unit tests, lint and formatting
- Vite example build and package dry-run (must identify `2.12.1`)
- published-package consumer verification
- bounded headless Chromium browser input smoke

The `pnpm release:check` wrapper covers many of those checks, but should only
be reported as executed when actually invoked. Chromium automation does not
certify Safari, Firefox, physical devices, accessibility, or other browsers.
Do not convert planned checks to passing claims until exact-head CI evidence
has been reviewed.
