## 11. Owner-assisted physical-device checklist

For each step, record: scenario ID, date, OS/browser/version, package version, viewport, DPR, input device, reduced-motion mode, starting phase, exact action, expected result, observed result, console errors, screenshot or short video, and PASS/FAIL/UNVERIFIED.

1. Physical standard mouse wheel: start at `intro`, normal input mode, desktop viewport. Wheel down once over the page body. Expect one adjacent move to `overview`, trace `wheel` with final `defaultPrevented=true`, no console errors. Capture short video and console.
2. Physical high-resolution trackpad: start at `intro`. Perform one smooth downward trackpad gesture over the page body. Expect accumulation to produce at most one adjacent move per accepted burst, no multi-phase skip. Capture video showing phase/status/trace.
3. Physical keyboard repeat: start at `intro`, focus body. Hold ArrowDown through repeat. Expect transition/cooldown to prevent unexpected phase skipping; rejected repeats preserve native behavior. Capture video and console.
4. Physical touch device: start at `intro` on phone/tablet. Swipe up once over the page body. Expect one adjacent move, trace `touchmove` or `touchend`, no stale gesture after touchcancel/interruption. Capture device video and console if available.
5. Desktop viewport: open preview at a representative desktop size. Expect all panels, controls, trace, observer outputs, and Canvas to remain usable. Capture screenshot and console.
6. Narrow mobile viewport: open preview around 390px width or equivalent device. Expect responsive single-column layout with usable controls. Capture screenshot/video and console.
7. Nested scroll: start at any phase, wheel/drag inside the `data-flow-ignore` nested scroll region. Expect nested content scrolls and phase does not change. Capture video and trace.
8. Page scroll rejection: at first/last boundary or during lock/cooldown, wheel the page body. Expect rejected navigation preserves native scroll when the page can scroll. Capture video and trace final `defaultPrevented=false` for rejected event.
9. Native controls: interact with text input, textarea, select, checkbox, regular button, regular anchor, and contenteditable. Expect native editing/activation without phase changes unless an accepted flow navigation owns the event. Capture video and console.
10. Canvas/WebGL observation: with Canvas mounted, navigate between phases and verify both observer outputs update with phase, phaseIndex, progress, direction, isTransitioning, and delta. Unmount Canvas and verify DOM phase/progress remain mounted; remount and verify observer output resumes. Capture video and console.
11. Normal and reduced motion: start in normal mode, navigate once, toggle reduced mode. Expect provider key remount resets phase state and shorter application transition duration. Toggle back and verify the same remount behavior. Capture video and console.
