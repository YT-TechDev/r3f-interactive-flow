## Provenance note: AGENT-CANVAS hash transcription correction

When the owner first reported the five raw-output SHA-256 values, the value
given for Run 2 (AGENT-CANVAS) was 65 hexadecimal characters —
`1c889ed62447749aa2bdd0c6a358b84d4b2f35d49bbadb71a95b47a169abdbd7a` — one
character longer than a valid SHA-256 digest, and it did not match the
SHA-256 actually computed from the file on disk. Before copying or
committing any raw output, this implementation session recomputed the
SHA-256 of every one of the five raw files directly from disk and compared
each to the reported value. Four matched exactly; AGENT-CANVAS did not. The
owner confirmed the file on disk was the true, unmodified Run 2 output and
that the discrepancy was a transcription error (one extra character inserted
while copying terminal output), and provided the corrected value —
`1c889ed6244749aa2bdd0c6a358b84d4b2f35d49bbadb71a95b47a169abdbd7a` (64
characters) — which matches the file's actual SHA-256 exactly. This is a
metadata transcription correction only: the raw AGENT-CANVAS file itself was
never modified, and the corrected 64-character hash is the value recorded in
`validation/agent-public-docs/runs/run-2026-07-25/AGENT-CANVAS/evidence.json`
and independently reproduced by `pnpm consumer:agent:verify` from the raw
file's actual bytes.
