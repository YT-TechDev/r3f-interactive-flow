# v1.8.0 Release Readiness

This document records release-readiness preparation for `r3f-interactive-flow@1.8.0` before any npm publish, git tag, GitHub Release, or milestone closeout action.

## Summary

v1.8.0 is a React and R3F bridge hardening release. It prepares the release artifacts for completed work that stabilizes the React provider, React progress reads, R3F frame bridge behavior, and client-facing entry compatibility without expanding the library scope.

For the detailed behavior baseline, see [React and R3F bridge baseline for v1.8.0](../react-r3f-bridge-v1.8.0.md).

## Release scope

- This release hardens the existing React and R3F bridge baseline.
- `FlowProvider` behavior coverage confirms provider snapshots, shared controls, navigation updates, lock and unlock state, transition option forwarding, children without Canvas, and import-time browser global safety.
- `useFlowProgress` behavior coverage confirms alignment with provider progress, transition updates, blocked navigation stability, multiple consumers without Canvas, and provider usage errors.
- `useFlowFrame` bridge coverage confirms frame callback registration, latest snapshot reads, transition completion synchronization, no-op navigation stability, and provider usage errors.
- Client-facing entry compatibility coverage confirms Client Component usage boundaries without requiring browser globals at module import time.
- Canvas-bound hook usage guidance is clarified for `useFlowFrame`.
- No source behavior changes are included in this release-prep PR.
