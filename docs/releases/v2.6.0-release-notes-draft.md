# r3f-interactive-flow v2.6.0

v2.6.0 is a focused browser lifecycle and input hardening minor release. It
includes two focused runtime input corrections, deterministic regression
coverage, and documentation alignment while preserving the stable v2 public
API and package boundary.

### Highlights

- Corrects touch gesture lifecycle behavior for semantically equivalent
  `ignore` selector rerenders (#423).
- Uses monotonic elapsed time for wheel burst inactivity and wheel, touch, and
  keyboard hook-local cooldown decisions (#424).
- Adds focused deterministic regression coverage for input rerender, target
  resolution, touch interruption, provider timing, and hook-local elapsed-time
  contracts (#384, #385, #386).
- Aligns README and input guide documentation with the proven input lifecycle,
  browser boundaries, time sources, and example option stability (#387).
- The optional browser harness remains deferred; #383 remains open and is not
  included in v2.6.0.

### Fixed behavior

- Committed touch gesture state is preserved across rerenders that provide
  semantically equivalent `ignore` selector arrays. Fresh equivalent inline
  arrays no longer discard a committed gesture merely because their array
  identity changed, while materially changed selectors still replace the
  relevant Effect and reset pending gesture/listener state as intended.
- Wheel burst inactivity and wheel, touch, and keyboard hook-local cooldowns now
  use monotonic elapsed time. The current implementation uses
  `performance.now()`, so wall-clock changes no longer distort these decisions.

### Hardened contracts

- Input rerender and target-resolution coverage now locks unresolved explicit
  refs never falling back to `window`, same-commit ref resolution, dynamic target
  replacement boundaries, and equivalent versus material option changes.
- Touch coverage now includes commitment and interruption behavior, missing
  `touches[0]`, `touchcancel`, and unmount/remount interruption.
- Provider and input elapsed-time coverage now includes the first-frame rAF
  baseline, non-negative handling for decreasing rAF timestamps, large positive
  deltas that complete a transition and consume remaining provider cooldown in
  the same update, zero-duration transitions plus cooldown, and monotonic
  hook-local cooldown behavior.

### Documentation

- The input guide and README files now document listener Effect setup and
  cleanup, exact target-resolution boundaries, unresolved explicit ref behavior,
  the absence of automatic mutable-ref tracking, dynamic target application
  responsibility, and accepted/rejected `preventDefault()` behavior.
- The docs also cover nested ignored/editable/actionable ancestor protection,
  wheel burst behavior, bounded single-touch semantics, keyboard input's lack of
  an `ignore` selector, provider and hook time-source inventory, bounded
  browser/background claims, and hoisted input option constants in examples.

### Compatibility

- No public API additions or removals.
- No public TypeScript type changes.
- No package export changes or new package subpaths.
- No runtime dependency additions.
- No peer dependency range changes.
- The root-only package boundary remains unchanged.
- The two runtime fixes are behavioral corrections within the existing API.
- No generalized gesture framework, E2E framework, or automated browser harness
  was added.

### Evidence boundaries

- v2.6.0 deterministic focused tests validate library contracts; they are not
  automated real-browser or physical-device certification.
- v2.6.0 did not rerun or expand the physical-device matrix.
- The prior v2.5.0 evidence remains bounded to representative desktop Chrome
  physical mouse, representative high-resolution trackpad, representative
  physical keyboard, and representative physical iPhone Safari touch. It did not
  include a completed physical-tablet lane.
- This release does not claim automated Chromium coverage, Playwright or Vitest
  Browser Mode coverage, cross-browser certification, Firefox/WebKit/Safari
  automation, physical-device certification, universal native-scroll behavior,
  universal trackpad behavior, deterministic hidden-tab behavior,
  deterministic OS/device sleep behavior, or broad background-timing guarantees.
