# v1.7.0 Release Readiness

This document records release-readiness preparation for `r3f-interactive-flow@1.7.0` before any npm publish, git tag, GitHub Release, or milestone closeout action.

## Summary

v1.7.0 is an input integration hardening release. It prepares the release artifacts for completed work that stabilizes combined browser input behavior, disabled and re-enabled input lifecycles, and custom input target retargeting without expanding the library scope.

For the detailed behavior baseline, see [Input integration baseline for v1.7.0](../input-integration-v1.7.0.md).

## Release scope

- This release hardens the existing input integration baseline.
- Cross-input lock and cooldown behavior is covered for the existing wheel, keyboard, and touch hooks.
- Combined wheel and keyboard input scenarios are covered.
- Combined touch and wheel input scenarios are covered.
- Disabled and re-enabled lifecycle behavior is aligned across input hooks.
- Custom input target retargeting behavior is hardened.
- No source behavior changes are included in this release-prep PR.
