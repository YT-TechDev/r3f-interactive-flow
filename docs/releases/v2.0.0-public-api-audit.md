# v2.0.0 Public API Audit

## Scope

This audit finalizes the stable public API review for v2.0.0. It covers the package entrypoint, explicit public type exports, package metadata, and current README guidance for the existing React, R3F, and input hooks.

The audit does not change source behavior, tests, package metadata, package exports, package version, dependencies, examples, or release automation.

## Public API surface

The stable runtime API remains intentionally small and centered on the package entrypoint exports:

- `FlowProvider`
- `useFlow`
- `useFlowProgress`
- `useFlowFrame`
- `useWheelInput`
- `useTouchInput`
- `useKeyboardInput`

The documented public type exports remain limited to the provider-adjacent transition options, R3F frame bridge types, and existing input hook option/target types:

- `FlowFrameCallback`
- `FlowFrameState`
- `FlowInputTarget`
- `FlowTransitionBaseOptions`
- `FlowTransitionOptions`
- `UseKeyboardInputOptions`
- `UseTouchInputOptions`
- `UseWheelInputOptions`

No new runtime export or public type export is added by this audit.

## Boundary confirmations

- Public usage continues to import from `r3f-interactive-flow`, not internal package paths.
- Package metadata continues to expose only the root package entrypoint and does not present internal modules as public subpath APIs.
- The React hooks remain documented for client-side React components under `FlowProvider`.
- `useFlowFrame` remains documented as Canvas-bound because it bridges to the React Three Fiber frame loop.
- The input hooks remain documented as optional browser input utilities that drive existing `next` and `prev` flow controls, not as a broad gesture system.
- README examples continue to use existing documented APIs and avoid non-existent package APIs.

## Out-of-scope confirmation

This audit does not introduce:

- public API expansion
- runtime dependency changes
- Next.js as a dependency
- router integration
- visual effects, animation timelines, camera presets, shader APIs, particle APIs, templates, CLI/codegen, or third-party animation wrappers
- npm publishing, git tags, GitHub Releases, or milestone closeout work

No shared AI chat, session, or task links are included.

## Result

The current package entrypoint API is ready to be treated as the v2.0.0 public contract. No release-blocking public API mismatch was found in the audited files, and no source, test, package export, package metadata, or dependency change is required for this task.
